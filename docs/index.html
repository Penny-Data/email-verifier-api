Bulk Email Verifier API (no SMTP)

A bulk email verifier API to validate an email list without SMTP. Per address: syntax, MX/DNS records, disposable domains, role accounts, free providers and typo suggestions. Pay per checked email; DNS failures are not billed.

Try it on Apify: pennydata/bulk-email-validator-no-smtp

What "no SMTP" means

It never contacts the recipient's mail server. It does an email syntax, MX and disposable check; it cannot confirm that a specific mailbox exists and does not claim to.

curl

export APIFY_TOKEN=your_token_here
curl -X POST "https://api.apify.com/v2/acts/pennydata~bulk-email-validator-no-smtp/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"emails":["jane@gmail.com","info@example.com","bob@mailinator.com","x@gmial.com","not-an-email"]}'

Node.js (18+)

const res = await fetch(
  `https://api.apify.com/v2/acts/pennydata~bulk-email-validator-no-smtp/run-sync-get-dataset-items?token=${process.env.APIFY_TOKEN}`,
  { method: 'POST', headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ emails: ['jane@gmail.com', 'bob@mailinator.com'] }) },
);
console.log(await res.json());

Python

import os, requests

resp = requests.post(
    "https://api.apify.com/v2/acts/pennydata~bulk-email-validator-no-smtp/run-sync-get-dataset-items",
    params={"token": os.environ["APIFY_TOKEN"]},
    json={"emails": ["jane@gmail.com", "bob@mailinator.com"]},
    timeout=300,
)
print(resp.json())
